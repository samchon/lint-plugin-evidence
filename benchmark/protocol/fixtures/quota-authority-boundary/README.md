# Quota authority boundary fixtures

These fixtures prove that a prepare authorization came from one live, bounded controller request. The exported prepare validator first applies `quota-prepare-authority.schema.json`, so missing members, extra retained members, and raw absolute monotonic readings cannot bypass shape validation before semantic checks. The controller generates a 256-bit random nonce, hashes the exact RFC 8785 canonical JSON projection `{authorityRequestId, phase, blockId, planSha256, subjects}`, and includes that request identity in the sanitized quota attestation. The local canonical encoder is admitted only for the schema-closed printable-ASCII projection where it is asserted RFC 8785-equivalent, not as a general JCS implementation. Prepare uses `planSha256: null`; start execution must pass the separate machine-readable start admission with a new request, `phase: start`, and the exact closed block-plan SHA-256.

The retained boundary records UTC request start and response receipt plus only the nonnegative monotonic elapsed delta. Absolute monotonic clock readings are private process state and must never be retained. Semantic validation requires the quota capture to fall inside the UTC interval, both UTC and monotonic durations to remain within 60 seconds, and their difference to remain within the pinned two-second clock-resolution tolerance. The boundary and quota state must agree on request nonce, request digest, phase, block, plan, ordered subject wave, and attestation digest.

Negative cases reject stale and future captures, reversed or invalid UTC, negative and unsafe elapsed values, timeout and clock disagreement, attestation substitution, a missing boundary, prepare-to-start replay, cross-block, cross-plan, cross-wave replay, and request nonce or digest substitution.
