This append-only addendum corrects the monetary-rate statement inherited through `current-freeze-standard-tier.md`. The official ChatGPT credit rate directly supports Standard Terra rates of 62.5 credits per million uncached input tokens, 6.25 per million cached input tokens, and 375 per million output tokens including reasoning. It does not state a ChatGPT provider-credit rate for `cacheWriteInputTokens`. The separate API prompt-caching guidance states a 1.25-times cache-write multiplier for API token pricing, but no direct source establishes that this multiplier transfers to ChatGPT provider credits. The previously stated value of 78.125 provider credits per million cache-write input tokens is therefore withdrawn from the executable price sheet.

No paid generation result, transcript, grade, gate result, time observation, token observation, or quality observation informed this correction. The canonical chain's frozen corpus sizes, Standard wall-time quantiles, exact provider-token priors, quality priors, coverage priors, censoring priors, campaign priors, and directly sourced Standard credit rates remain unchanged. Exact cache-write input tokens remain a measured token category. Provider-credit totals, monetary expected-cost rows, and a provider-credit stop threshold are unavailable until a direct official ChatGPT credit source or applicable account contract establishes that category's rate.

The API-only 1.25 multiplier remains contextual evidence, not an execution rate. A missing cache-write rate blocks every paid benchmark request even when official source snapshots for the other rates are pinned. USD conversion remains separately optional and null; it is not the cause of this launch block.
