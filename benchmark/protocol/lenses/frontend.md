# Frontend lens

Trace every user-visible acceptance criterion and SDK operation into reachable routes, screens, forms, lists, detail states, session behavior, interactions, accessibility semantics, responsive layouts, loading, empty, success, error, retry, and browser journeys. Then walk every authored route, screen, action, state store, and journey back to its requirement or operation owner.

Check stale or missing SDK calls, client-only authorization assumptions, incomplete validation, unreachable behavior, optimistic updates without rollback, inconsistent cached state, missing errors, inaccessible controls, non-responsive layouts, and journeys that do not exercise production rendering and transport.

Report only concrete omissions, partial implementations, contradictions, semantic defects, or test-oracle gaps with exact criterion and artifact citations.
