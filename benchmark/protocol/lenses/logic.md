# Logic lens

Trace every business rule, authorization policy, role, ownership rule, visibility rule, lifecycle, state transition, concurrency condition, transaction, integrity invariant, audit requirement, security constraint, privacy rule, recovery behavior, and non-functional obligation through each provider and consumer.

Walk both directions: requirements and schema invariants into logic, then every branch, error, side effect, and provider back to an owner. Look for rules enforced only in the UI, race-prone read-then-write sequences, inconsistent state paths, unsafe error disclosure, missing rollback, stale derived values, and non-functional claims with no executable or inspectable support.

Report only concrete omissions, partial implementations, contradictions, semantic defects, or test-oracle gaps with exact criterion and artifact citations.
