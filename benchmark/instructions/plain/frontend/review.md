# Plain Frontend Review

Perform a new, exhaustive frontend review.

1. Re-read every requirement.
2. Inspect every route, screen, component, and state transition.
3. Inspect every form, omission, error path, and SDK call.
4. Inspect every browser journey and live interaction.
5. Run every frontend, browser, and live gate.

Review the actual files and behavior one by one. Searches, summaries, inventories, build results, and previous reviews never replace inspection. Fix every defect at its owner and restart at item 1. Complete only when one full pass needs no edits and every gate passes.
