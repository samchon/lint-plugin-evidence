# Plain Frontend Review

Perform a new, exhaustive frontend review. Re-read every requirement, then inspect every route, screen, component, state transition, form, omission, error path, SDK call, browser journey, and live interaction.

Review the actual files and behavior one by one. Searches, summaries, inventories, build results, and previous reviews may help navigation but never replace inspection.

Fix every defect at its owner and restart the review from the first requirement. Complete only when one full pass needs no edits and all frontend, browser, and live gates pass.
