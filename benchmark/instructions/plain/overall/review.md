# Plain Overall Review

Perform a new, exhaustive whole-project review. Re-read every requirement and trace it through the database, API, backend, generated SDK, frontend, tests, browser journeys, and live behavior. Trace every implemented artifact back to a real requirement.

Inspect the actual files and behavior one by one. Searches, summaries, inventories, build results, and earlier reviews may help navigation but never replace inspection.

Fix every defect at its owner, regenerate downstream output, and restart from the first requirement. Complete only when one full pass needs no edits and all project gates pass.
