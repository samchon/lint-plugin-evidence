# Plain Overall Review

Perform a new, exhaustive whole-project review.

1. Re-read every requirement.
2. Trace each requirement through the database, API, backend, generated SDK, frontend, tests, browser journeys, and live behavior.
3. Trace every implemented artifact back to a real requirement.
4. Run every project gate.

Inspect the actual files and behavior one by one. Searches, summaries, inventories, build results, and earlier reviews never replace inspection. Fix every defect at its owner, regenerate downstream output, and restart at item 1. Complete only when one full pass needs no edits and every gate passes.
