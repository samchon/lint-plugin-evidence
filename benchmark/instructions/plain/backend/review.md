# Plain Backend Review

Perform a new, exhaustive backend review. Re-read every requirement, then inspect every database model and relation, DTO and property, operation, branch, authorization rule, error path, test, generated contract, and connection between them.

Review the actual files one by one. Searches, summaries, inventories, build results, and previous reviews may help navigation but never replace inspection.

Fix every defect at its owner and restart the review from the first requirement. Complete only when one full pass needs no edits and all backend gates pass. Do not review the frontend.
