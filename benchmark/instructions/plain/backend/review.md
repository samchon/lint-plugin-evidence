# Plain Backend Review

Perform a new, exhaustive backend review.

1. Re-read every requirement.
2. Inspect every database model and relation.
3. Inspect every DTO, property, operation, branch, authorization rule, and error path.
4. Inspect every test, generated contract, and connection between artifacts.
5. Run every backend gate.

Review the actual files one by one. Searches, summaries, inventories, build results, and previous reviews never replace inspection. Fix every defect at its owner and restart at item 1. Complete only when one full pass needs no edits and every backend gate passes. Do not review the frontend.
